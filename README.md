# Dosimetria de Ruído — Gêmeo Digital

Simulador 3D (Three.js) para o ensino de avaliação da exposição ocupacional ao ruído: estamparia com prensas,
trabalhadora no posto, dosímetro pessoal com operação e calibração demonstradas passo a passo, instalação no ombro
(zona auditiva) e dosimetria de uma jornada acelerada com resultados pelos critérios da NHO-01 (q = 3) e da NR-15
Anexo 1 (q = 5), pós-calibração (±1 dB) e relatório.

Uso didático. Valores de ruído e jornada são simulados. Sem afiliação com fabricantes de instrumentos.

## Créditos
- Three.js (MIT) via jsDelivr.
- Trabalhadora: modelo 3D gerado pelo autor (Tripo) a partir de foto de referência; alternativa `?avatar=rocketbox` com avatares Microsoft Rocketbox (MIT) — `assets/rocketbox/LICENSE.md`.
- Personagens ao fundo: modelo de exemplo do repositório three.js, carregado do CDN.
